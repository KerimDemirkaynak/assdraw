Using the mouse and keyboard

Left mouse button


On the canvas, your left mouse button does the followings:


  • In any drawing mode except Scale/Rotate and Bilinear Transformation, pointing/hovering on a point or a control point highlights the point, showing the point's coordinates and highlighting the line/curve the point belongs to.
  • In Drag drawing mode, you can drag points and control points to change the shape.
  • Also in Drag mode, if you can drag on empty area of the canvas to select multiple points (see Multiple points selection), then drag on of the selected points to move all of them in-sync.
  • In M, L or B drawing mode, left-clicking on the canvas adds an M, L or B command (move, line or bezier curve) to the end of the commands string. The point associated to the command is added to the canvas when you depress the mouse button and can still be moved around until you release the button, at which time the command is finalized (for bezier curve, the control points are generated at that moment). Left-clicking and dragging from an existing point on the canvas adds the new command/point immediately after the existing one.
  • In Scale/Rotate and Bilinear Transformation modes, drag an edge or a vertex of the bounding rectangle to scale or transform the shape.


Right mouse button


On the other hand, your right mouse button is used as follow:


  • In all drawing modes except Scale/Rotate, right-dragging the canvas (i.e. holding right button down while moving the mouse pointer over the canvas) pans the canvas, moving the shape within the viewpoint.
  • In Scale/Rotate drawing mode, right-dragging rotates the shapes around the shape's center.

Mousewheel


Mousewheel is mainly used for zooming. Mousewheel up zooms in (scale up) while mousewheel down zooms out (scale down).
