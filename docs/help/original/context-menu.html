Context menu

When in any drawing mode other than Scale/Rotate and Bilinear Transformation, double-right-clicking (i.e double-clicking using right mouse button) pops up context menu that, depending on where you click, allows you to perform specific actions:


  1. Move [0,0] here
    Reposition origin (coordinate [0,0]) to the position double-clicked on canvas without moving the shape. As a result, all the points that make up the shape undergo linear translation. This gives the same result as (left-)dragging the origin crosshair.

  2. Mode: xxxxxx
    Switch to a particular drawing mode

  3. Convert to Bezier curve (B command)
    Self-explanatory

  4. Convert to line (L command)
    Ditto

  5. Smooth connection
    Available for any connection points in between two Bezier curves; enable smooth connection mode on that point makes sure the curves are smooth on that connection whenever you drag any of the two control points nearest to the connection of the two curves.
