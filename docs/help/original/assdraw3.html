ASSDraw3 overview

ASSDraw3 is a tool for designing shapes to be used in ASS subtitle file. The main feature of ASSDraw3 is that you can design the shapes you want using mouse and ASSDraw3 automatically generates the drawing commands, which are basically vector drawing commands.


ASS subtitle


It is a format of subtitle file that can be used to embed subtitles to a video. It is very flexible format that supports stylings, text animation (e.g. karaoke), shapes etc. ASSDraw3 focuses on the shapes feature that ASS subtitle format supports. It does not care at all about subtitle.


Drawing commands


Imagine drawing a shape using a pen (real world pen that uses ink). To draw a square on a piece of paper, you first position your pen above a particular position on the paper. Then you press the pen tip lightly on the paper surface and start moving the pen in a straight path to produce, well, a straight line on the paper. Then you do the same for three other edges of the square. Once the tip of the pen reaches the starting point, you get a square.


That is basically how shapes are drawn in ASS subtitle. There are commands to instruct the renderer to move to a specific point, draw a line to that point, draw a bezier curve etc. A string of cleverly-choreographed commands renders shapes ranging from as simple as a square to more complex shapes like a snow speck or a christmas tree. Commands for a square can be easily written by hand but it takes lots of imagination to design a complex logo without visual aids.


Commands fully supported by ASSDraw3:

  • M x y
    Move to point (x,y), closing the current shape using a line connecting the current point to the previous M
  • L x y
    Draw a straight line from current point to (x,y)
  • B x1 y1 x2 y2 x y
    Draw a Bezier curve begining from current point and ending at (x,y) with (x1,y1) and (x2,y2) being the internal guide/control points


N x y (move to point (x,y) without closing the current shape) entered in the Drawing Commands input field will be converted to L command.


S (spline), P (extend spline) and C (close spline) commands are not supported.
