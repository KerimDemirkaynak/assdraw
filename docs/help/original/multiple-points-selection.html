Multiple points selection

To select multiple points, first switch to Drag mode if you haven't done so. Point to an empty space on canvas and start dragging. A dashed selection rectangle will appear and resize following your mouse dragging.


Any points of the shape that fall within the rectangle will be selected. Likewise, any points that are not included in the rectangle are unselected, unless if either Ctrl or Alt key is depressed, in which case the behaviors are as follows:


Depressed Key

Behavior

Ctrl

Add points to the existing selection

Alt

Remove points from selection

None

Start a new multi-selection, reseting any existing selection
