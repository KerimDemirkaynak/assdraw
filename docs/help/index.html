ASSDraw3 3.1

Draw vector shapes for Advanced SubStation Alpha subtitles. This offline guide works on Windows and Linux.

Read the complete illustrated manual (22 topics and 14 illustrations). The original Windows CHM is also included. Manual opens this HTML edition so downloaded Windows packages do not show a blocked, empty CHM pane.

Drawing and editing

Choose Move (M), Line (L), or Bezier (B), then click or drag on the canvas. A new M starts a separate contour. Use Drag mode to move points and Bezier control handles. Hold Shift to switch temporarily to Drag mode.

F1–F7 select the drawing and transformation tools. Scale/Rotate and Bilinear transform the drawing using the bounding handles. Right-double-click opens context actions for points or the canvas.

Tracing an image

Drag an image file onto the canvas, or use Paste with an image in the clipboard. Enable Pan drawing and/or Pan background to choose which layer right-drag and mouse-wheel gestures affect. Set background image opacity in the Background menu; its default is configurable in Settings.

Coloring and ASS output

Choose Coloring, click a filled sub-shape, then double-click it to choose its fill color. Holes remain attached to their enclosing contour. The Drawing commands pane accepts multiline input; Enter applies it. Copy ASS copies one line including color, outline, and alpha tags. Paste that line into an ASS event in Aegisub.

History and shape library

Ctrl+Z undoes a drawing edit and Ctrl+Y redoes it, without moving the tracing image or restoring the canvas view. Use Save canvas in the Shapes Library to store a drawing. Double-click a stored shape to load it. Colors are retained.

Language

The Language menu offers English, Turkish, French, German, Spanish, Traditional Chinese, and Vietnamese. Changes apply immediately and are saved for the next launch. System Default follows a supported system language, otherwise English. Language selection does not change ASS numeric formatting.

Workspace and preferences

Dock or undock toolbars and panels through Workspace. Reset workspace restores the default layout. Apply commits preference edits; Revert restores the current saved settings shown in the panel. Backgrounds and language changes do not modify drawing geometry.
